# שאלון ללקוח חדש

ממלאים את זה (אפשר בצ'אט, במילים פשוטות), ו-Claude הופך את התשובות לקובץ `clients/<שם>.json` ומריץ:

```bash
npm run new-client -- clients/<שם>.json
```

נוצרת תיקייה `bots/<שם>/` עם בוט מלא, נעול, ורשימת משימות (`CHECKLIST.md`) לפי החבילה. מה שלא יודעים עדיין, משאירים ריק. `npm run check` יראה מה חסר.

---

## א. בסיס (כל לקוח)
1. **איזו חבילה?** מזכירה / פרו / פרימיום.
2. **איזה סוג עסק?**
   - **שירות:** הובלות, מנעולן, טכנאי, ניקיון, קבלן. הבוט אוסף פרטים, ובעל העסק נותן מחיר.
   - **השכרה:** צימרים, דירות נופש. הבוט מחשב מחיר ובודק זמינות בעצמו.
3. שם העסק, כמו שהלקוחות מכירים אותו.
4. שם בעל העסק, ובאיזה לשון הבוט מדבר (זכר או נקבה).
5. המספר של בעל העסק להתראות (וואטסאפ).
6. אזור שירות.
7. משפט או שניים על העסק (כמה שנים, מה מיוחד).
8. איך בעל העסק מדבר עם לקוחות? קצר או מפורט, "אחי" או רשמי. אם יש, צילומי מסך של 3 עד 5 שיחות אמיתיות.
9. מה הבוט עונה למי שכותב רק "היי"?
10. שבת: הבוט עונה כרגיל, או אומר שהעסק סגור?

## ב. עסק שירות
1. רשימת השירותים.
2. **מה לברר מכל לקוח** (הכי חשוב). למשל בהובלות: מאיפה לאן, תאריך, כמה חדרים, קומה ומעלית, פריטים כבדים.
3. שעות עבודה (ימים ושעות), ומה אומרים למי שכותב מחוץ לשעות (למשל "חוזר מחר בבוקר").
4. מחירים: אסור לתת מחיר בכלל? או שיש מחיר התחלתי שמותר להגיד?
5. מה נחשב דחוף ומגיע לבעל העסק מיד.
6. מה אסור להגיד או להבטיח.
7. שאלות שחוזרות, והתשובה הקבועה לכל אחת (ביטוח, חשבונית, אזורים).
8. מה אומרים ללקוח מחוץ לאזור.
9. תמונות של עבודות (קישורים), אם יש.

## ג. עסק השכרה (לכל דירה או צימר)
1. שם, ומשפט תיאור (חדרים, מיטות, נוף).
2. כמה אנשים: מבוגרים, ילדים, תינוקות.
3. מחירון: אמצע שבוע, חמישי, סופ"ש, תוספת לילד, דמי ניקיון. הנחות, חגים, מינימום לילות.
4. מה יש בדירה (ג'קוזי, בריכה, חניה, מזגן, נוף לים...).
5. שעות כניסה ויציאה.
6. כתובת, קוד כניסה, Wi-Fi, חניה. נשלחים רק אחרי אישור הזמנה.
7. קישורי יומן מ-Airbnb ו-Booking, אם יש.
8. תמונות.
9. מדיניות ביטול, ואיך מאשרים הזמנה (בעל העסק מאשר, או מקדמה בקישור).

## ד. חבילת פרו (בנוסף)
1. האם הלקוח באייפון או באנדרואיד? (שיחות שלא נענו)
2. וואטסאפ רגיל או עסקי? (חייב עסקי)
3. שם המשתמש באינסטגרם.
4. קישור לביקורת בגוגל, או שצריך להקים פרופיל עסקי.
5. לאתר: דומיין (אם יש), לוגו, תמונות, צבעים שהוא אוהב.
6. נושאים לפוסטים: מבצעים, עבודות לפני ואחרי, טיפים.

## ה. חבילת פרימיום (בנוסף)
1. תקציב חודשי למודעות (משולם ישירות למטא), וגישה לחשבון המודעות.
2. מיתוג: יש לוגו? רוצים חדש?
3. כרטיסי ביקור ומדבקות: כמה ולאן (רכב, חנות, חשבוניות).
4. רשימת לקוחות ישנים שהסכימו לקבל הודעות, אם יש.
5. בהשכרה: תוספות שאפשר למכור לאורח (יציאה מאוחרת, סלסלה) ובכמה.
