# הבוט של דוד (3 דירות נופש + תיווך לשותפים)

בוט וואטסאפ שעונה ללקוחות של דוד, מציע את הדירה המתאימה, מחשב מחיר, שולח תמונות, אוסף פרטים ורושם הזמנה. לקוח שלא מתאים לאף דירה (למשל זוג ושלושה ילדים, כשהדירה הכי גדולה מתאימה לזוג ושני ילדים) עובר כ"ליד להעברה" לדוד או ישר לבעל דירה שותף, ודוד מקבל עמלה. תקלות מגיעות לשותף שמטפל בהן, לא לדוד.

**המצב:** הבוט בנוי ונבדק, 32 בדיקות עוברות, כולל בדיקת עומס של 150 לקוחות. נשאר רק להכניס את הנתונים של דוד ולחבר את החשבונות. `npm run check` מראה בדיוק מה חסר.

## מה הבוט עושה

**ללקוח**
- עונה תוך שניות, 24/7, בשפה שהלקוח כותב בה.
- מבין הודעות קוליות (תמלול עם Cloudflare Workers AI) ותמונות (למשל תמונה של תקלה בזמן שהייה).
- מתאים דירה לפי מבוגרים, ילדים ותינוקות, ומחשב מחיר מדויק לפי אמצע שבוע, סופ"ש, עונות, מינימום לילות ודמי ניקיון. המחיר מחושב בקוד, לא על ידי המודל.
- אם הדירה שביקש תפוסה, מציע דירה אחרת. אם הבעיה היא רק מינימום לילות, מציע להאריך.
- שולח תמונות של הדירה.
- רושם בקשת הזמנה. שני לקוחות לא יכולים לקבל את אותו לילה, גם אם הם מזמינים באותה שנייה.
- לקוח שקיבל מחיר ונעלם מקבל הודעת מעקב אחרי 3 שעות, ושוב אחרי 22 שעות.
- הודעות סביב השהייה: יום לפני ההגעה (קוד כניסה ו-Wi-Fi), ביום ההגעה, בבוקר העזיבה, בקשת ביקורת, והזמנה לחזור אחרי 120 יום.
- רשימת מבצעים בהסכמה בלבד. "הסר" מוריד מהרשימה.

**לדוד**
- התראה על כל הזמנה. מאשר עם `אושר B123`.
- "🔁 ליד להעברה" עם הסיבה והשותפים שמתאימים, או העברה ישירה לשותף. רושם עמלה עם `נסגר R123 500`.
- כל בוקר ב-07:00: מי נכנס, מי יוצא, מה מחכה לאישור. גם למנקה, אם הוגדר.
- בימי ראשון ורביעי ב-10:00: לילות פנויים בשבוע הקרוב, עם הצעה לשלוח מבצע.
- סיכום שבועי בראשון ב-09:00.
- פקודות: `פנוי`, `חסום 2 2027-03-01 2027-03-04`, `חסימות`, `שחרר 5`, `מבצע: טקסט`, `היום`, `סיכום`. כל הודעה אחרת מחזירה את רשימת הפקודות.

**לנו (השותף שמטפל בתקלות)**
- כל תקלה נשלחת לשותף בוואטסאפ: מה קרה, איזה לקוח, ומה הלקוח קיבל. אותה תקלה נשלחת לכל היותר פעם ב-15 דקות.
- דוח פנימי בראשון ב-09:00: עלות Claude, צפי חודשי, עלות ממוצעת ללקוח, ותקלות. דוד לא רואה אותו.
- התראה אם העלות היומית עוברת את התקרה (`AGENCY.dailyBudgetUsd`).
- `/health?token=...` מחזיר מצב, את השגיאה האחרונה ועלות ב-24 השעות האחרונות. אפשר לחבר אותו לשירות ניטור חינמי כמו UptimeRobot.

## לעלות לאוויר: צ'קליסט

### 1. נתונים מדוד
1. את התשובות מהשאלון (`bot-form/david/`) מכניסים ל-`src/config.js`. אפשר לבקש מ-Claude: "הנה התשובות של דוד, תכניס לקונפיג".
2. מגדירים `AGENCY.techPhone` עם המספר של השותף.
3. מריצים `npm run check` עד שאין חוסמים, ומחליפים ל-`DRAFT = false`.

### 2. Cloudflare (בתוכנית Workers Paid)
```bash
cd bots/david && npm install
```
```bash
npx wrangler d1 create david-bot
```
את ה-id שחוזר מכניסים ל-`wrangler.toml`, ואז:
```bash
npx wrangler d1 migrations apply david-bot --remote
```
אחר כך מגדירים את הסודות, כל אחד בפקודה נפרדת: `ANTHROPIC_API_KEY`, `WA_TOKEN`, `WA_PHONE_NUMBER_ID`, `WA_APP_SECRET`, `WA_VERIFY_TOKEN`, `HEALTH_TOKEN` (מחרוזת אקראית).
```bash
npx wrangler secret put ANTHROPIC_API_KEY
```
ולבסוף:
```bash
npx wrangler deploy
```

### 3. Meta (WhatsApp Cloud API)
1. מחברים את המספר של דוד. אפשר להמשיך להשתמש בו גם באפליקציה (coexistence).
2. Webhook: הכתובת היא `https://<worker>/webhook`, ה-Verify token הוא הערך של `WA_VERIFY_TOKEN`, ונרשמים ל-`messages`.
3. מאמתים את העסק (Business Verification) ומוסיפים אמצעי תשלום.
4. מאשרים תבניות (Utility, בעברית), ושמים את השמות ב-`TEMPLATES` ב-config. ב-`owner_alert` מגדירים גם `WA_NOTIFY_TEMPLATE`.

| שם מוצע | סוג | הטקסט |
|---|---|---|
| `owner_alert` | Utility | עדכון מהבוט: {{1}} |
| `stay_reminder` | Utility | היי {{1}}, תזכורת לקראת ההגעה מחר: {{2}} |
| `stay_welcome` | Utility | {{1}}, {{2}} צריך משהו? פשוט תכתוב כאן. |
| `stay_checkout` | Utility | בוקר טוב {{1}}. {{2}} |
| `stay_review` | Utility | {{1}}, {{2}} |
| `come_back` | Marketing | היי {{1}}, {{2}} |
| `offer` | Marketing | היי {{1}}, {{2}} להסרה כתבו "הסר" |

### 4. בדיקה לפני שבוע הניסיון
1. `curl "https://<worker>/health?token=..."` צריך להחזיר `ok: true`.
2. שולחים מהטלפון 10 עד 15 שיחות אמיתיות: זוג, משפחה גדולה (צריכה לעבור לתיווך), תאריכים תפוסים, הודעה קולית, תמונה, ו"הסר".
3. דוד שולח `עזרה` ומקבל את רשימת הפקודות.
