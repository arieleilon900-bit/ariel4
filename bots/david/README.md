# הבוט של דוד (3 דירות נופש + תיווך לשותפים)

בוט וואטסאפ שעונה ללקוחות של דוד, מציע את הדירה המתאימה, מחשב מחיר, אוסף פרטים ורושם הזמנה. לקוח שלא מתאים לאף דירה (למשל זוג ושלושה ילדים, כשהדירה הכי גדולה היא לזוג ושני ילדים) עובר כ"ליד להעברה" לדוד או ישר לבעל דירה שותף, ודוד מקבל עמלה.

השאלון ללקוח: `bot-form/david/index.html`. כל תשובה ממנו נכנסת ל-`src/config.js`.

## מה בנוי ועובד (17 בדיקות עוברות)

| | |
|---|---|
| פרופיל נפרד לכל דירה | מחיר אמצע שבוע וסופ"ש, עונות וחגים, מינימום לילות, ניקיון, קיבולת, מה יש, חוקים |
| התאמה לפי הרכב | מבוגרים, ילדים ותינוקות (תינוק לא נספר אם הדירה מגדירה כך) |
| זמינות | הזמנות של הבוט + סנכרון יומן מ-Airbnb, Booking וגוגל (iCal). בקשה שממתינה תופסת את התאריכים ל-48 שעות |
| מחיר | מחושב בקוד, לא על ידי המודל |
| הצעת דירה חלופית | אם הדירה שביקשו תפוסה או קטנה, מציע דירה אחרת של דוד |
| תיווך | מזהה שאין התאמה (קיבולת, תאריכים, תקציב, בריכה, חיות וכו'), מבקש אישור מהלקוח (חוק הפרטיות), אוסף פרטים, שולח לדוד "🔁 ליד להעברה" עם השותפים שמתאימים, או ישר לשותף עם העתק לדוד |
| מעקב עמלות | דוד כותב `נסגר R123 500` ← נרשם. מופיע בסיכום השבועי |
| בקשת הזמנה | סיכום, אישור לקוח, התראה לדוד. דוד כותב `אושר B123` ← הלקוח מקבל אישור |
| הודעת בוקר 07:00 | מי נכנס, מי יוצא, מה מחכה לאישור. גם למנקה, אם יש |
| סיכום שבועי (ראשון 09:00) | פניות, בקשות, הזמנות, הכנסה, לידים שהועברו, נסגרו, עמלות |
| מעקב ללקוח שנעלם | אחרי 3 שעות ואחרי 22 שעות (בתוך חלון 24 השעות של וואטסאפ). "הסר" עוצר |
| כל שפה | עונה בשפה שהלקוח כותב בה |

## מה עוד לא בנוי

1. **הודעות קוליות.** כרגע הבוט מבקש לכתוב בטקסט. צריך שירות תמלול.
2. **תזכורת יום לפני ההגעה, הודעת ברוכים הבאים, תזכורת יציאה, בקשת ביקורת.** כל אלה נשלחים מחוץ לחלון 24 השעות, אז צריך תבניות מאושרות של Meta לפני שאפשר לבנות.
3. **תשלום אוטומטי.** כרגע שולח קישור קבוע (ביט, פייבוקס או דף אשראי). אישור אוטומטי כשהכסף נכנס דורש חיבור לספק הסליקה.
4. **שליחת תמונות.** כרגע שולח קישור לתמונות.
5. **רשימת תפוצה ומבצעי רגע אחרון.**

## הפעלה

ההפעלה דורשת: מספר וואטסאפ עסקי ב-WhatsApp Cloud API (Meta), מפתח Anthropic, וחשבון Cloudflare.

```bash
cd bots/david
npm install
npm test
```

```bash
npx wrangler kv namespace create BOT_KV
```

את ה-id שחוזר מכניסים ל-`wrangler.toml`. אחר כך מגדירים את הסודות:

```bash
npx wrangler secret put ANTHROPIC_API_KEY
```

```bash
npx wrangler secret put WA_TOKEN
```

```bash
npx wrangler secret put WA_PHONE_NUMBER_ID
```

```bash
npx wrangler secret put WA_APP_SECRET
```

```bash
npx wrangler secret put WA_VERIFY_TOKEN
```

```bash
npx wrangler deploy
```

ב-Meta: Webhook URL = `https://<worker>/webhook`, Verify token = מה שהוגדר ב-`WA_VERIFY_TOKEN`, ונרשמים ל-`messages`.

**התראות לדוד ולשותפים:** וואטסאפ מאפשר הודעה חופשית רק אם האדם כתב למספר ב-24 השעות האחרונות. לכן צריך לאשר ב-Meta תבנית אחת עם פרמטר `{{1}}` (למשל `owner_alert`: "עדכון מהבוט: {{1}}") ולהגדיר `WA_NOTIFY_TEMPLATE`. הבוט עובר לתבנית רק כשהודעה רגילה נחסמת.

**נעילת טיוטה:** כל עוד `DRAFT = true` ב-`config.js`, הבוט מתעלם מהודעות (הנתונים שם הם דוגמה). לבדיקה בלי לשנות את זה: `ALLOW_DRAFT=1`. לבדיקה בלי לשלוח הודעות אמיתיות: `DRY_RUN=1`.

## מבנה

| קובץ | מה יש בו |
|---|---|
| `src/config.js` | הדירות, השותפים וההגדרות של דוד (מהשאלון) |
| `src/logic.js` | מחיר, קיבולת, זמינות, החלטה על תיווך. בלי רשת, נבדק ב-`test/logic.test.js` |
| `src/prompt.js` | ההנחיות לבוט, נבנות מה-config |
| `src/tools.js` | `find_apartments`, `create_booking_request`, `refer_lead`, `notify_owner` |
| `src/agent.js` | השיחה מול Claude (Opus 5.5, עם fallback אוטומטי אם המודל מסרב) |
| `src/owner.js` | הפקודות של דוד, הודעת בוקר, סיכום שבועי, הודעות מעקב |
| `src/whatsapp.js` | קבלה ושליחה ב-WhatsApp Cloud API, אימות חתימה |
| `src/store.js` | שמירה ב-Cloudflare KV |
