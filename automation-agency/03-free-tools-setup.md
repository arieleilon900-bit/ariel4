# 03. הכלים: מה, למה וכמה עולה

כל הכלים כאן חינמיים בשבוע הראשון. המחירים והמגבלות נבדקו באוקטובר 2026, אבל הם משתנים; כדאי להציץ בדף המחירים של כל כלי לפני שמבטיחים משהו ללקוח.

## למה Make ולא n8n / Zapier
- **Zapier:** המסלול החינמי מוגבל מאוד ויקר לגדול.
- **n8n:** מצוין וחינמי אם מתקינים לבד על שרת, אבל זה עוד שרת לתחזק. אחרי 5 לקוחות שווה לשקול.
- **Make:** ממשק גרפי, מודולים מוכנים ל-Google Sheets, Tally, פייסבוק ו-WhatsApp Cloud, ומסלול חינמי שמספיק ללקוח קטן.

## הטריק שחוסך כסף: חשבון Make לכל לקוח
כל לקוח פותח חשבון Make חינמי **משלו**, על המייל שלו, ומזמין אתכם כמנהלים (Organization ← Invite).
- 1,000 הקרדיטים החינמיים מספיקים לבעל מקצוע ממוצע (חישוב בקובץ 04).
- הלקוח הבעלים של המערכת. זה משדר אמינות ("זה שלך, לא בני ערובה").
- אם לקוח גדל ועובר את המכסה, הוא משדרג ב-~$11 לחודש, על חשבונו.

## וואטסאפ: איך זה עובד באמת
**לדמו: Green-API.** מחברים את הטלפון של אחד מכם (רצוי מספר שני, לא האישי) כמו WhatsApp Web, ומקבלים כתובת API ששולחת הודעות. המסלול החינמי מוגבל ל-3 צ׳אטים, וזה בדיוק מה שצריך לדמו: הטלפון שלכם והטלפון של בעל העסק בפגישה.

**ללקוח משלם: WhatsApp Cloud API (הרשמי של Meta).**
- שירותים לא רשמיים שמתחברים לוואטסאפ רגיל עלולים לגרום לחסימת המספר. **אל תסכנו את המספר הראשי של העסק של הלקוח.**
- בדרך הרשמית: הודעות שהלקוח של העסק יזם (הוא כתב ראשון) חינמיות בחלון של 24 שעות. הודעה יזומה (למשל מענה לטופס, מעקב על הצעה) נשלחת כ"תבנית" מאושרת מראש. תבנית מסוג Utility (שירות) עולה בישראל אגורות בודדות להודעה; תבנית שיווקית עולה יותר. בדקו את טבלת המחירים העדכנית של Meta.
- התבניות מתאשרות בדרך כלל תוך דקות עד שעות. נוסחים מוכנים בקובץ 04.
- Meta מאפשרת היום ברוב המקרים לחבר לפלטפורמה גם מספר שכבר עובד באפליקציית WhatsApp Business, כך שבעל העסק ממשיך לענות מהטלפון כרגיל. בודקים את זה בזמן ההקמה; אם לא אפשרי, פותחים מספר וירטואלי נפרד להודעות האוטומטיות.

**אם ההקמה הרשמית נתקעת:** בשבוע הראשון אפשר להתחיל עם התראה לבעל העסק במייל ובוואטסאפ ממספר הדמו שלכם, ותשובה אוטומטית ללקוח במייל. המערכת כבר שווה כסף גם ככה, ומשדרגים לוואטסאפ ללקוח כשהאישור מגיע.

## העלאת דף הנחיתה לאוויר (GitHub Pages, חינם)
הדרך הכי פשוטה: ריפו נפרד ונקי לדף.
1. ב-GitHub: New repository בשם `one-rishon` (ציבורי).
2. Add file ← Upload files ← גוררים את `site/index.html` ← Commit.
3. Settings ← Pages ← Source: Deploy from a branch ← `main` / root ← Save.
4. אחרי דקה-שתיים הדף באוויר ב-`https://<שם-המשתמש>.github.io/one-rishon/`.
5. **לפני העלאה** מחליפים בקובץ: את `972524666175` במספר הוואטסאפ שלכם (פורמט בינלאומי בלי 0 ובלי מקפים), ואת השם "עונה ראשון" אם תחליטו לשנות.

דומיין משלכם (כ-₪50 לשנה) לא חובה בשבוע הראשון. קישור של GitHub מספיק לשלוח בוואטסאפ.
