# תוכנית עבודה: הבוט של חנן המנעולן

**סטטוס:** נסגר. התקבלו ₪1,000 מקדמה ותעודת עוסק מורשה, ויש חשבונית שודרג. חנן לקח את כל 18 הסעיפים.
**יעד:** דמו עובד על מספר בדיקה תוך 2–3 ימים, ומערכת מלאה על המספר האמיתי תוך 2–3 שבועות.

## איך המערכת בנויה
| חלק | כלי | מי פותח |
|---|---|---|
| וואטסאפ רשמי | WhatsApp Cloud API של Meta | אריאל (עם הפייסבוק שלו) |
| השרת | Cloudflare Workers + מסד נתונים D1 + Cron | השותף |
| ה-AI שמנהל את השיחה | Claude API (Anthropic) | השותף |
| תמלול הודעות קוליות | Workers AI (Whisper) בתוך Cloudflare | כלול ב-Cloudflare |
| טבלת לקוחות | Google Sheets עם Service Account | השותף |
| קבלות | API של יש חשבונית | חנן מוציא מפתח, אריאל מעביר |
| הקוד | בריפו, בתיקייה `bots/hanan-locksmith/` | Claude |

**כלל אבטחה:** מפתחות וסיסמאות **לא שולחים בצ׳אט**. מכניסים אותם רק לשרת, עם הפקודה `wrangler secret put` (ההוראות בקובץ ההתקנה).

## שלב 1: היום (הכול במקביל)

### אריאל
- [ ] **1.1 תיק עסקי ב-Meta:** https://business.facebook.com ← "Create a business portfolio" ← שם: `חנן המנעולן - פתרונות נעילה מתקדמים` ← הפרטים של העסק של חנן.
- [ ] **1.2 התחלת אימות עסק:** בתיק העסקי ← Settings ← Security Center ← Start verification ← מעלים את תעודת העוסק המורשה. (לוקח מכמה ימים ועד שבועיים, ולכן מתחילים היום.)
- [ ] **1.3 אפליקציה למפתחים:** https://developers.facebook.com/apps ← Create App ← Use case: "Connect with customers through WhatsApp" ← מחברים לתיק העסקי מ-1.1.
- [ ] **1.4 מספר בדיקה:** באפליקציה ← WhatsApp ← API Setup. Meta נותנים מספר בדיקה חינמי. ב-"To" מוסיפים את המספר שלך, של השותף ושל חנן (עד 5 מספרים), ומאשרים בקוד שמגיע.
- [ ] **1.5 לשלוח ל-Claude (זה לא סודי):** `Phone number ID` ו-`WhatsApp Business Account ID` מדף API Setup.
- [ ] **1.6 לשלוח לחנן את טופס השאלות:** https://arieleilon900-bit.github.io/ariel4/bot-form/
- [ ] **1.7 לבקש מחנן:**
  - קישור לכתיבת ביקורת בגוגל: בפרופיל העסק שלו בגוגל ← "לקבלת ביקורות". אם אין לו פרופיל עסקי בגוגל, צריך לפתוח (https://business.google.com).
  - מפתח API מיש חשבונית. הוא נכנס לחשבון ← הגדרות ← API, או מבקש מהתמיכה שלהם. **שיעביר לך ישירות, לא בקבוצה.**
  - תיעוד ה-API: לבקש מהתמיכה של יש חשבונית את קובץ התיעוד, ולשאול אם אפשר לקבל רשימה של מסמכים חדשים עם הטלפון של הלקוח.

### השותף
- [ ] **2.1 Cloudflare:** https://dash.cloudflare.com/sign-up (חינם).
- [ ] **2.2 Anthropic:** https://console.anthropic.com ← מוסיפים כרטיס ← טוענים $10 ← API Keys ← Create Key. שומרים את המפתח במקום בטוח.
- [ ] **2.3 Google Cloud, לטבלה:**
  1. https://console.cloud.google.com ← פרויקט חדש: `hanan-bot`.
  2. APIs & Services ← Enable APIs ← **Google Sheets API** ← Enable.
  3. IAM & Admin ← Service Accounts ← Create ← שם: `hanan-bot` ← Done.
  4. נכנסים ל-Service Account ← Keys ← Add key ← JSON ← יורד קובץ. **שומרים אותו, לא שולחים.**
  5. https://sheets.new ← גיליון בשם `לקוחות - חנן המנעולן` ← Share ← מוסיפים את המייל של ה-Service Account (נגמר ב-`iam.gserviceaccount.com`) כ-Editor.
  6. **לשלוח ל-Claude:** את ה-ID של הגיליון (החלק בכתובת שבין `/d/` ל-`/edit`).
- [ ] **2.4 התקנות במחשב:**
  1. Node.js LTS: https://nodejs.org
  2. בטרמינל: `npm install -g wrangler` ואז `wrangler login`.
  3. Git: https://git-scm.com, ואחר כך `git clone https://github.com/arieleilon900-bit/ariel4.git`.
