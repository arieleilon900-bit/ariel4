# מה נשאר לשותף כדי שהבוט יהיה מוכן לחנן

בערך שעתיים וחצי. הכלל כמו תמיד: סיסמה, טוקן או מפתח נכנסים רק ל-GitHub Secrets, לא בצ'אט.

**1. Anthropic: שהמוח לא ייעצר (10 דקות)**
1. https://console.anthropic.com ← Billing ← Auto reload ← להדליק: כשהיתרה יורדת מתחת ל-5 דולר, טוען 20 דולר.
2. Limits ← תקרה חודשית 30 דולר.
3. צילום מסך של שני המסכים לאריאל.

**2. 360dialog: הדרך הרשמית למספר של חנן (20 דקות)**
1. https://hub.360dialog.com ← נרשמים עם המייל של העסק.
2. בוחרים מסלול ומכניסים כרטיס אשראי.
3. **לא מוסיפים מספר.** את המספר של חנן מחברים רק ביום החיבור, כשהוא לידנו.
4. נכנסים למסך של הוספת מספר ובודקים שיש אפשרות לחבר מספר שכבר עובד באפליקציית WhatsApp Business. צילום מסך לאריאל, ויוצאים בלי להמשיך.

**3. Meta: חשבון עסקי על השם של חנן (20 דקות)**
1. https://business.facebook.com ← Create a business portfolio.
2. שם העסק בדיוק כמו בתעודת העוסק של חנן. כתובת וטלפון של העסק.
3. Settings ← Security Center ← Start verification ← מעלים את תעודת העוסק (ה-PDF שחנן שלח).
4. אם הוא מבקש אתר או משהו שאין לנו, עוצרים ושולחים צילום מסך לאריאל.

**4. בדיקה אחרונה של הבוט (45 דקות)**
צריך טלפון אחד שישחק "לקוח". שולחים לאריאל את המספר שלו, ואריאל מבקש מ-Claude להדליק את הבוט רק למספר הזה.
1. מהלקוח: "היי, ננעלתי מחוץ לבית", עונים לבוט, שולחים תמונה, הקלטה קולית וכתובת, ואז "תודה".
   ← צריך להגיע סיכום **אחד**, בערך 3 דקות אחרי ההודעה האחרונה.
2. לא עונים על הסיכום חצי שעה ← צריכה להגיע תזכורת "עדיין לא חזרת".
3. עונים על הסיכום (החלקה ימינה): "בדרך 20" ← הלקוח מקבל שחנן בדרך.
4. כותבים לבוט "טבלה", פותחים את הקישור, ולוחצים "טופל" ליד הלקוח ← אחרי 3 שעות הלקוח מקבל בקשת ביקורת עם הקישור לגוגל.
5. מלקוח חדש: "דחוף, הילד נעול באוטו" ← צריך להגיע מיד.
6. כל דבר שלא קרה כמו שכתוב פה: צילום מסך לאריאל.
בסוף הבדיקה מכבים שוב את הבוט.

**5. מה מבקשים מחנן (רק אחרי 1-4)**
1. למלא את הטופס: שעות, אזורים, מחירים, מקרים דחופים.
2. מספר להתראות. חייב להיות שונה מהמספר של העסק.
3. לעדכן את אפליקציית WhatsApp Business בטלפון של העסק.
4. לקבוע איתו 15 דקות לחיבור.

**ביום החיבור (15 דקות, עם חנן)**
1. ב-360dialog: מוסיפים מספר ← בוחרים את האפשרות של אפליקציית WhatsApp Business ← חנן סורק QR מהאפליקציה שלו ומאשר.
2. מעתיקים את ה-API Key ← GitHub Secrets בשם `D360_API_KEY`.
3. **קבלות:** חנן נכנס ליש חשבונית (משתמש בעלים) ← תפריט ← מפתחות ← ניהול מפתחות ← יוצר מפתח חדש. את שני הערכים מקלידים ישר ל-GitHub Secrets: `YESH_USERKEY` ו-`YESH_SECRET`. לא שולחים אותם בוואטסאפ.
4. Claude מעביר את הבוט למספר של חנן, מדליק אותו, ובודקים יחד הודעה אמיתית, וגם קבלה אחת לטלפון שלכם.
5. **לכבות אצל חנן את ההודעות האוטומטיות של WhatsApp Business:** הגדרות ← כלים לעסקים ← הודעת פתיחה: כבוי. הודעת היעדרות: כבוי. אחרת לקוחות יקבלו גם אותן וגם את הבוט.
6. שולחים לחנן את המדריך שלו.

**חיבור המייל של חנן (כשאריאל אומר. 5 דקות)**
הסיכומים לחנן נשלחים מהג'ימייל של העסק אל המייל של חנן. בחינם.
1. בג'ימייל של העסק: https://myaccount.google.com/security ← "אימות דו-שלבי" צריך להיות מופעל.
2. https://myaccount.google.com/apppasswords ← שם: `hanan-bot` ← Create ← מתקבלת סיסמה של 16 אותיות.
3. GitHub Secrets (שלושה סודות):
   - `GMAIL_USER` = כתובת הג'ימייל של העסק
   - `GMAIL_APP_PASSWORD` = הסיסמה מסעיף 2
   - `OWNER_EMAIL` = המייל של חנן
4. אומרים ל-Claude "המייל בפנים". הוא מעלה את הבוט מחדש ושולח מייל בדיקה.
5. חנן: באפליקציית ג'ימייל בטלפון, להגדיר צליל להתראות מהבוט, כדי שפנייה דחופה תישמע.
