## חלוקת תפקידים
- **שותף א׳, "הבונה":** מקים את הכלים, בונה את האוטומציות, מעלה את דף הנחיתה, מתקין אצל לקוחות.
- **שותף ב׳, "המוכר":** בונה רשימת לקוחות, מתקשר, שולח הודעות, קובע פגישות.
- **שניכם יחד:** פגישות דמו וסגירה.

אם אחד מכם כבר בונה אתרים לעסקים קטנים (כמו בתיקייה `website-builder/clients` בריפו הזה), **הלקוחות הקיימים שלו הם הלקוח הראשון הכי קל.** הם כבר סומכים עליו, ויש להם אתר עם טופס או כפתור וואטסאפ שאפשר לחבר אליו את המערכת. תתחילו מהם.
