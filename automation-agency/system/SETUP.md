# הקמת המערכת למכוני לייזר: 20 דקות, ₪0

המערכת יושבת כולה בתוך Google Sheets. אין Make, אין כרטיס אשראי.
מה צריך: חשבון Gmail, טלפון עם וואטסאפ לדמו (עדיף מספר שני, לא האישי), מחשב.

> הגרסה לקבלנים נמצאת בתיקייה `system/contractors/`. הגרסה כאן מותאמת למכוני לייזר וקוסמטיקה.

## מה המערכת עושה
| מתי | מה נשלח ללקוחה |
|---|---|
| השאירה פרטים | תוך דקה: "קיבלתי, אני באמצע טיפול ואחזור אלייך תוך שעה. בוקר או אחר הצהריים?" + התראה לבעלת המכון |
| לא קבעה תור | מעקב אחרי יום, 3 ימים ושבוע |
| נקבע תור | תזכורת יום לפני + תזכורת שעתיים לפני |
| לא הגיעה | "פספסנו אותך היום, לקבוע תור חדש?" |
| הגיעה לטיפול | אחרי 42 יום (ניתן לשינוי): "הגיע הזמן לטיפול הבא". אם לא קבעה, עוד תזכורת אחרי 10 ימים. כך בכל טיפול בסדרה |
| סיימה את הסדרה | בקשת ביקורת בגוגל (הסדרה מסתיימת לבד אחרי מספר הטיפולים שהוגדר, ברירת מחדל 8) |

**ולבעלת המכון:** כל יום ראשון ב-9:00 דוח שבועי בוואטסאפ: לידים חדשים, תורים שנקבעו, טיפולים, הברזות, וכמה תזכורות המערכת שלחה בשבילה.

הודעות מתוזמנות נשלחות רק בין 9:00 ל-20:00.

## מה בעלת המכון עושה (מהטלפון, באפליקציית Google Sheets)
| קרה | משנה בגיליון |
|---|---|
| קבעה תור עם לקוחה | `סטטוס` ← **נקבע תור**, ו`מועד תור` ← למשל `14/10/2026 16:30` |
| הלקוחה הגיעה | `סטטוס` ← **הגיעה** (המערכת סופרת טיפולים ומתזמנת את הבא) |
| לא הגיעה | `סטטוס` ← **לא הגיעה** |
| קבעה את הטיפול הבא | שוב **נקבע תור** + מועד חדש |
| סדרה באורך אחר (למשל 6 טיפולים) | בעמודה `טיפולים בסדרה` כותבים 6 (ריק = ברירת המחדל מההגדרות) |
| סיימה סדרה / לא מעוניינת | **סיימה** / **לא רלוונטי** (המערכת מפסיקה לשלוח) |

לקוחה קיימת שלא נכנסה דרך טופס: מוסיפים שורה ידנית עם שם, טלפון וסטטוס.

## שלב 1: וואטסאפ (Green-API), 5 דקות
1. [console.green-api.com](https://console.green-api.com) ← נרשמים ← **Create instance** ← מסלול **Developer** (חינם).
2. בטלפון של הדמו: וואטסאפ ← הגדרות ← **מכשירים מקושרים** ← קישור מכשיר ← סורקים את ה-QR.
3. כשהסטטוס `authorized`, מעתיקים: `apiUrl`, `idInstance`, `apiTokenInstance`.

> המסלול החינמי שולח ל-3 צ׳אטים בלבד, וזה מספיק לדמו. ללקוחה משלמת עוברים למסלול בתשלום או לוואטסאפ הרשמי (קובץ 04).

## שלב 2: הגיליון והקוד, 10 דקות
1. [sheets.new](https://sheets.new) ← גיליון חדש בשם `מערכת לקוחות - דמו`.
2. **Extensions ← Apps Script**.
3. ב-`Code.gs`: מוחקים הכול ומדביקים את הקוד. **+** ← **HTML** ← שם: `Form` ← מדביקים את הטופס. שמירה.
4. **גלגל השיניים (Project Settings)** ← Time zone: **(GMT+03:00) Jerusalem**.
5. בוחרים את הפונקציה `setup` ← **Run** ← מאשרים הרשאות: Review permissions ← החשבון ← **Advanced** ← **Go to ... (unsafe)** ← **Allow**. (זה הקוד שלכם בחשבון שלכם.)
6. בגיליון נוצרו הלשוניות `לקוחות`, `הגדרות` ו-`יומן` (יומן האירועים שממנו נבנה הדוח השבועי).

## שלב 3: הגדרות ובדיקה, 3 דקות
בלשונית `הגדרות` ממלאים: שם המכון, שם בעלת המכון, הטלפון שלכם (להתראות), כתובת, ושלושת הפרטים מ-Green-API.
רעננו (F5) ← תפריט **עונה ראשון**:
1. **שליחת הודעת בדיקה** ← מגיעה הודעה? מחובר.
2. **ליד לדוגמה** ← נוספת שורה ומגיעות שתי הודעות.

## שלב 4: הטופס כקישור, 2 דקות
**Deploy ← New deployment** ← Web app ← Execute as: **Me**, Who has access: **Anyone** ← Deploy ← מעתיקים את הקישור.
זה הטופס של המכון. בפגישה: בעלת המכון ממלאת אותו מהטלפון שלה ומקבלת וואטסאפ עם השם של המכון שלה.

> שיניתם קוד? Deploy ← Manage deployments ← עריכה ← Version: New version.

## שלב 5: לראות את התזכורות עובדות (לדמו)
1. בשורה של הליד: `סטטוס` ← **נקבע תור**, `מועד תור` ← מחר בשעה שעוד לא עברה.
2. **עונה ראשון ← הרצת תזכורות ומעקבים עכשיו** ← מגיעה תזכורת "מחר בשעה...".
3. `סטטוס` ← **הגיעה** ← הרצה ← הסטטוס הופך ל**בסדרה**, `טיפולים` = 1, ו`מעקב הבא` = עוד 42 יום.
4. כדי להראות את "הגיע הזמן לטיפול הבא": משנים את `מעקב הבא` לתאריך של היום ומריצים.

המתזמן רץ לבד כל שעה, והדוח השבועי יוצא כל יום ראשון ב-9:00 (שני הטריגרים נוצרים ב-`setup`). לבדיקה: **עונה ראשון ← שליחת הדוח השבועי עכשיו**.

## חיבור לידים מפייסבוק ואינסטגרם
רוב המכונים מקבלים לידים מטופס של מודעה ממומנת. שתי דרכים:
- **הכי פשוט:** מחליפים בקמפיין את הטופס של פייסבוק בקישור לטופס של המערכת.
- **בלי לשנות קמפיין:** ב-Make (חינם) תרחיש אחד: `Facebook Lead Ads › Watch Leads` ← `HTTP › Make a request` (POST לקישור ה-Web app, JSON: `{"name":"...","phone":"...","job":"...","source":"פייסבוק"}`).

גם טופס באתר או Tally יכולים לשלוח לקישור ה-Web app (שדות `name`, `phone`, `city`, `job`, `notes`).

## הכנת דמו לפגישה (5 דקות)
