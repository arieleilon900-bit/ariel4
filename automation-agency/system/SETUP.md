# הקמת המערכת: 20 דקות, ₪0

המערכת יושבת כולה בתוך Google Sheets. אין Make, אין מגבלת תרחישים, אין כרטיס אשראי.
מה צריך: חשבון Gmail, טלפון עם וואטסאפ לדמו (עדיף מספר שני, לא האישי), מחשב.

## שלב 1: וואטסאפ (Green-API), 5 דקות
1. נכנסים ל-[console.green-api.com](https://console.green-api.com) ונרשמים עם המייל של העסק.
2. **Create instance** ← בוחרים מסלול **Developer** (חינם).
3. בדף ה-instance מופיע QR. בטלפון של הדמו: וואטסאפ ← הגדרות ← **מכשירים מקושרים** ← קישור מכשיר ← סורקים.
4. הסטטוס משתנה ל-`authorized`. מעתיקים לפנקס שלושה ערכים:
   - `apiUrl` (נראה כמו `https://7105.api.greenapi.com`)
   - `idInstance` (מספר)
   - `apiTokenInstance` (מחרוזת ארוכה)

> המסלול החינמי מאפשר הודעות ל-3 צ׳אטים בלבד. זה בדיוק מספיק לדמו: הטלפון שלכם, של השותף ושל בעל העסק בפגישה. ללקוח משלם עוברים לחשבון רשמי (קובץ 04, "מעבר לוואטסאפ הרשמי").

## שלב 2: הגיליון והקוד, 10 דקות
1. [sheets.new](https://sheets.new) ← גיליון חדש בשם `מערכת לידים - דמו`.
2. בתפריט: **Extensions ← Apps Script** (הרחבות ← Apps Script).
3. בעורך שנפתח:
   - מוחקים את כל מה שכתוב ב-`Code.gs` ומדביקים את כל התוכן של הקובץ [`Code.gs`](Code.gs).
   - לוחצים **+** ליד Files ← **HTML** ← קוראים לו `Form` (בלי .html) ← מוחקים את התוכן ומדביקים את [`Form.html`](Form.html).
   - שמירה (Ctrl+S).
4. למעלה בחירת הפונקציה `setup` ← **Run**.
5. גוגל יבקש הרשאות: **Review permissions** ← בוחרים את החשבון ← "Google hasn't verified this app" ← **Advanced** ← **Go to ... (unsafe)** ← **Allow**.
   זה תקין: זה הקוד שלכם, בחשבון שלכם.
6. חוזרים לגיליון. נוצרו שתי לשוניות: `לידים` ו-`הגדרות`.

## שלב 3: ההגדרות, 3 דקות
בלשונית `הגדרות`, עמודת **ערך**:
| הגדרה | מה לשים |
|---|---|
| שם העסק / שם בעל העסק | לדמו: "שיפוצי יוסי" / "יוסי". לפני פגישה: השם של העסק שאתם פוגשים |
| טלפון בעל העסק | המספר שלכם (מקבל את ההתראות) |
| GREEN_API_URL / GREEN_ID_INSTANCE / GREEN_API_TOKEN | שלושת הערכים משלב 1 |
| קישור לביקורת בגוגל | לדמו אפשר להשאיר. אצל לקוח: מהפרופיל שלו בגוגל |
| הודעות | אפשר לשנות כל נוסח. `{שם}` וכו׳ מתמלאים לבד |

רעננו את הגיליון (F5). מופיע תפריט חדש: **עונה ראשון**.
1. **עונה ראשון ← שליחת הודעת בדיקה לבעל העסק**: מגיעה אליכם הודעה בוואטסאפ? מחובר.
2. **עונה ראשון ← ליד לדוגמה**: נוספת שורה, ומגיעות שתי הודעות (כ"לקוח" וכ"בעל עסק").

## שלב 4: הטופס כקישור, 2 דקות
1. ב-Apps Script: **Deploy ← New deployment** ← גלגל השיניים ← **Web app**.
2. Execute as: **Me**. Who has access: **Anyone**. ← **Deploy**.
3. מעתיקים את ה-**Web app URL**. זה הטופס של העסק.
4. פותחים אותו בטלפון, ממלאים, ותוך שניות מגיע וואטסאפ. **זה הדמו שמראים בפגישה.**

> שיניתם קוד? Deploy ← **Manage deployments** ← עריכה (עיפרון) ← Version: **New version** ← Deploy. הקישור נשאר אותו קישור.

## שלב 5: בדיקת המעקב
1. בלשונית `לידים` משנים בשורה את `סטטוס` ל-`נשלחה הצעה`.
2. **עונה ראשון ← הרצת מעקב יומי עכשיו** ← בעמודה `מעקב הבא` נכנס תאריך עוד יומיים.
3. לדמו: משנים את התאריך ל**היום** ומריצים שוב ← מגיעה הודעת מעקב 1, `שלב מעקב` = 1.
4. משנים `סטטוס` ל-`בוצע` ← מריצים ← מגיעה בקשת ביקורת.

המעקב רץ לבד כל יום ב-10:00 (הטריגר נוצר ב-`setup`).

## לחבר טופס שכבר קיים (אתר / Tally)
הכתובת של ה-Web app מקבלת גם לידים מבחוץ:
- **Tally:** Integrations ← Webhooks ← מדביקים את ה-Web app URL. שדות שהכותרת שלהם כוללת "שם", "טלפון", "עיר", "עבודה", "הערות" מזוהים לבד.
- **טופס HTML באתר:** `<form method="post" action="WEB_APP_URL">` עם שדות `name`, `phone`, `city`, `job`, `notes`.
- **JSON:** POST עם `{"name":"...","phone":"...","job":"..."}`.

## הכנת דמו לפגישה (5 דקות)
File ← **Make a copy** של הגיליון ← בהגדרות משנים לשם העסק של הלקוח ← Deploy חדש מהעותק.
בעל העסק ממלא את הטופס מהטלפון שלו ומקבל וואטסאפ עם **השם של העסק שלו**. זה הרגע שסוגר.
