# 04. בניית האוטומציות, צעד אחר צעד

שני תרחישים ב-Make מכסים את כל שלוש האוטומציות. זה חשוב, כי במסלול החינמי מותר רק 2 תרחישים פעילים.

| תרחיש | מתי רץ | מה עושה |
|---|---|---|
| **A. ליד חדש** | מיד כשמישהו ממלא טופס | הודעה ללקוח, התראה לבעל העסק, שורה בגיליון |
| **B. מעקב יומי** | כל יום ב-10:00 | הודעות מעקב על הצעות מחיר + בקשות ביקורת |

**זמן בנייה בפעם הראשונה:** תרחיש A כ-90 דקות, תרחיש B כ-60 דקות. אצל הלקוח השני והלאה: משכפלים (Clone / Export Blueprint) ומחליפים חיבורים, כ-30 דקות.

---

## שלב 0: הגיליון
1. Google Sheets ← File ← Import ← מעלים את `templates/client-sheet.csv` ← "Replace spreadsheet".
2. שם הלשונית: `לידים`. שם הקובץ: `מערכת לידים - [שם העסק]`.
3. על עמודת `סטטוס` מוסיפים רשימה נפתחת (Data ← Data validation ← Dropdown) עם הערכים:
   `חדש`, `נשלחה הצעה`, `נסגר`, `בוצע`, `לא רלוונטי`.
   זו העמודה היחידה שבעל העסק נוגע בה. הוא מעדכן אותה מאפליקציית Sheets בטלפון.

**העמודות:**
| עמודה | מי ממלא | הסבר |
|---|---|---|
| תאריך | המערכת | מתי הגיע הליד |
| שם, טלפון, עיר, סוג עבודה, הערות | המערכת (מהטופס) | |
| מקור | המערכת | אתר / פייסבוק / ידני |
| סטטוס | **בעל העסק** | הרשימה הנפתחת |
| סכום הצעה | בעל העסק (לא חובה) | לדוח החודשי |
| מעקב הבא | המערכת | תאריך ההודעה הבאה, בפורמט `YYYY-MM-DD` |
| שלב מעקב | המערכת | 0–3, כמה הודעות מעקב נשלחו |
| ביקורת נשלחה | המערכת | תאריך שליחת בקשת הביקורת |

## שלב 1: הטופס (Tally)
1. tally.so ← Create form ← כותרת: "השאירו פרטים ונחזור אליכם היום".
2. שדות: **שם** (Short answer), **טלפון** (Phone number, חובה), **עיר**, **סוג עבודה** (Multiple choice: שיפוץ מטבח / שיפוץ אמבטיה / שיפוץ כללי / אחר), **הערות** (Long answer).
3. Settings ← Language: Hebrew. Publish.
4. הקישור לטופס נכנס לאתר של הלקוח (כפתור "קבלו הצעת מחיר"), לביו באינסטגרם ולפוסטים בפייסבוק. Tally נותן גם קוד הטמעה (Embed) לאתר.

**לקוח שמריץ מודעות לידים בפייסבוק:** במקום Tally משתמשים במודול `Facebook Lead Ads › Watch Leads` (צריך שהלקוח יוסיף אתכם כמנהלים בעמוד העסקי). כל השאר זהה.

## שלב 2: וואטסאפ לדמו (Green-API)
1. green-api.com ← הרשמה ← Create instance ← מסלול **Developer** (חינם).
2. סורקים את ה-QR עם הוואטסאפ של הטלפון של הדמו (WhatsApp ← מכשירים מקושרים).
3. מעתיקים לקובץ סודי (Bitwarden): `apiUrl`, `idInstance`, `apiTokenInstance`.
4. בדיקה מהירה בדפדפן של הקונסולה: יש שם כפתור לשליחת הודעת ניסיון. שלחו לעצמכם.

## תרחיש A: ליד חדש
ב-Make: Create a new scenario. בונים את המודולים לפי הסדר:

### A1. Tally › Watch New Responses
מחברים את חשבון Tally, בוחרים את הטופס. (זה טריגר מיידי.)

### A2. Tools › Set multiple variables
מנרמלים את מספר הטלפון לפורמט בינלאומי (054-1234567 ← 972541234567):
- `phone_digits` = `replace(<טלפון מהטופס>; /\D/g; emptystring)`
- `phone_intl` = `if(startsWith(phone_digits; "972"); phone_digits; "972" + substring(phone_digits; 1))`
- `first_name` = `first(split(<שם>; " "))`

### A3. Google Sheets › Add a Row
גיליון: `מערכת לידים`, לשונית: `לידים`. ממפים:
- תאריך: `formatDate(now; "DD/MM/YYYY HH:mm"; "Asia/Jerusalem")`
- שם, טלפון (`phone_intl`), עיר, סוג עבודה, הערות: מהטופס
- מקור: `אתר`
- סטטוס: `חדש`
- שלב מעקב: `0`

### A4. HTTP › Make a request (הודעה ללקוח)
- URL: `{{apiUrl}}/waInstance{{idInstance}}/sendMessage/{{apiTokenInstance}}`
  (מחליפים בערכים שלכם מ-Green-API)
- Method: `POST`
- Body type: `Raw`, Content type: `JSON (application/json)`
- Request content:
```json
{
  "chatId": "{{phone_intl}}@c.us",
  "message": "היי {{first_name}}, כאן יוסי משיפוצי יוסי 👋\nקיבלתי את הפנייה שלך לגבי {{סוג עבודה}}. אני באמצע עבודה כרגע ואחזור אליך היום עד 18:00.\nבינתיים, אם יש לך תמונות של המקום אפשר לשלוח לי לפה, זה יעזור לי לתת הצעה מדויקת."
}
```
`\n` הוא ירידת שורה. לא להקליד Enter אמיתי בתוך הטקסט, זה שובר את ה-JSON.

### A5. HTTP › Make a request (התראה לבעל העסק)
אותו דבר, רק ש-`chatId` הוא המספר של בעל העסק, וההודעה:
```json
{
  "chatId": "9725XXXXXXXX@c.us",
  "message": "🔔 ליד חדש מהאתר\nשם: {{שם}}\nטלפון: {{phone_intl}}\nעיר: {{עיר}}\nעבודה: {{סוג עבודה}}\nהערות: {{הערות}}\n\nכבר שלחתי לו הודעה שתחזור עד 18:00.\nלוואטסאפ איתו: https://wa.me/{{phone_intl}}"
}
```

### A6. בדיקה
1. Run once ← ממלאים את הטופס מהטלפון.
2. בודקים: הודעה הגיעה לטלפון של "הלקוח", התראה הגיעה ל"בעל העסק", שורה נוספה בגיליון.
3. מפעילים: מתג **ON** בתחתית התרחיש.
4. Scenario settings ← לוודא שהתראות שגיאה נשלחות למייל (ברירת המחדל).

**קרדיטים:** כ-5 לכל ליד. 60 לידים בחודש = 300 קרדיטים.

## תרחיש B: מעקב יומי (הצעות מחיר + ביקורות)
### B1. Google Sheets › Search Rows
- לשונית `לידים`, Filter: `סטטוס` = `נשלחה הצעה` **OR** `סטטוס` = `בוצע`.
- Maximum number of returned rows: 200.
- תזמון התרחיש (השעון בטריגר): **Every day, 10:00**. לא כל 15 דקות! זה שורף קרדיטים.

### B2. Router עם 3 מסלולים
מוסיפים Router אחרי B1. לכל מסלול יש Filter (לוחצים על הקו):

**מסלול 1: הצעה חדשה שנשלחה (מתחילים לספור)**
- Filter: `סטטוס` = `נשלחה הצעה` **AND** `מעקב הבא` Does not exist (ריק).
- Google Sheets › Update a Row (Row number מ-B1):
  `מעקב הבא` = `formatDate(addDays(now; 2); "YYYY-MM-DD")`, `שלב מעקב` = `0`.

**מסלול 2: הגיע הזמן להודעת מעקב**
- Filter: `סטטוס` = `נשלחה הצעה` **AND** `parseDate(מעקב הבא; "YYYY-MM-DD")` Datetime operators: Less than or equal to `now` **AND** `שלב מעקב` Numeric less than `3`.
- HTTP › Make a request: שולח ללקוח הודעה לפי השלב. ב-`message` כותבים:
```
{{if(שלב מעקב = 0; "היי " + first(split(שם; " ")) + ", רציתי לוודא שההצעה שלי הגיעה ושאין שאלות. אם משהו לא ברור אשמח להסביר 🙂"; if(שלב מעקב = 1; "היי " + first(split(שם; " ")) + ", חוזר אליך לגבי ההצעה. אם המחיר או הלו״ז לא מתאימים, תגיד לי. בדרך כלל אפשר למצוא פתרון."; "היי " + first(split(שם; " ")) + ", אני סוגר את הלו״ז לחודש הקרוב ורציתי לבדוק אם לשמור לך מקום. אם החלטת ללכת על משהו אחר, הכול טוב, רק תעדכן אותי 🙏"))}}
```
- Google Sheets › Update a Row:
  `שלב מעקב` = `שלב מעקב + 1`,
  `מעקב הבא` = `formatDate(addDays(now; if(שלב מעקב = 0; 3; 5)); "YYYY-MM-DD")`.

התוצאה: הודעה אחרי יומיים, עוד אחת 3 ימים אחר כך, ואחרונה 5 ימים אחר כך. כשבעל העסק משנה סטטוס ל-`נסגר` או `לא רלוונטי`, המעקב נעצר לבד.

**מסלול 3: עבודה הסתיימה ← בקשת ביקורת**
- Filter: `סטטוס` = `בוצע` **AND** `ביקורת נשלחה` Does not exist.
- HTTP › Make a request:
```
"היי {{first(split(שם; " "))}}, תודה שבחרת בנו! 🙏 אם יצאת מרוצה, ביקורת קצרה בגוגל עוזרת לנו מאוד: https://g.page/r/XXXXXXXX/review"
```
- Google Sheets › Update a Row: `ביקורת נשלחה` = `formatDate(now; "YYYY-MM-DD")`.

**איפה משיגים את קישור הביקורת:** בעל העסק נכנס בגוגל ל"פרופיל העסק שלי" ← "לקבלת ביקורות" (Ask for reviews) ← מעתיק את הקישור.

**קרדיטים:** 1 לחיפוש + 2 לכל הודעה. בעל מקצוע ממוצע: 150–250 בחודש. יחד עם תרחיש A, בערך 500 מתוך 1,000. נשאר מרווח.

## מעבר לוואטסאפ הרשמי אצל לקוח משלם (WhatsApp Cloud API)
עושים את זה ביחד עם הלקוח בשיחת ההקמה, כי צריך את הפרטים והכרטיס שלו.
1. business.facebook.com: הלקוח יוצר (או כבר יש לו) Business Portfolio ומוסיף אתכם כמנהלים.
2. developers.facebook.com ← Create App ← Business ← מוסיפים את מוצר **WhatsApp**.
3. מחברים מספר טלפון ומאמתים ב-SMS. מוסיפים אמצעי תשלום של הלקוח (WhatsApp Manager ← Payment).
4. יוצרים **System User** עם הרשאות WhatsApp ומפיקים Token קבוע.
5. יוצרים תבניות ב-WhatsApp Manager ← Message templates. **קטגוריה: Utility.** משתנים מסומנים `{{1}}`, `{{2}}`:

| שם תבנית | טקסט |
|---|---|
| `lead_received` | היי {{1}}, קיבלנו את הפנייה שלך לגבי {{2}}. נחזור אליך היום עד 18:00. אפשר לשלוח פה תמונות של המקום. |
| `quote_followup` | היי {{1}}, רצינו לוודא שהצעת המחיר הגיעה אליך ושאין שאלות. אפשר לענות פה. |
| `job_done_review` | היי {{1}}, תודה שבחרת בנו. אם יצאת מרוצה, נשמח לביקורת קצרה: {{2}} |

6. ב-Make מחליפים את מודולי ה-HTTP במודול `WhatsApp Business Cloud › Send a Template Message`, ממלאים את המשתנים, ובודקים שוב.

התראה לבעל העסק (A5) יכולה להמשיך לצאת מאותו מספר: כשבעל העסק כתב פעם אחת למספר המערכת, נפתח חלון של 24 שעות. הכי פשוט: תבנית Utility נוספת `owner_alert`, או התראה במייל.

## תוספת: שיחה שלא נענתה ← וואטסאפ (אנדרואיד בלבד)
מוכרים את זה כשדרוג אחרי שהלקוח רואה תוצאות.
1. בטלפון של בעל העסק: מתקינים **MacroDroid** (חינם עד 5 מאקרו).
2. Trigger: `Call Missed` (כל המספרים, או רק מספרים שלא באנשי הקשר).
3. Action: `HTTP Request` ← POST לכתובת Webhook של Make (`Webhooks › Custom webhook` בתרחיש נפרד, או כמסלול נוסף), עם מספר המתקשר.
4. ב-Make: שולחים למתקשר "היי, ראיתי שהתקשרת. אני באמצע עבודה, איך אפשר לעזור? אפשר לכתוב לי פה" ורושמים בגיליון.

באייפון אין טריגר לשיחה שלא נענתה. שם משתמשים בהודעת "מחוץ לשעות" המובנית של WhatsApp Business.

## צ׳קליסט לפני שמוסרים ללקוח
- [ ] ממלאים טופס אמיתי מטלפון זר ← הודעה הגיעה תוך פחות מדקה.
- [ ] מסמנים שורה `נשלחה הצעה` ← מריצים את B ידנית (Run once) ← `מעקב הבא` התמלא.
- [ ] משנים ידנית את `מעקב הבא` לתאריך של היום ← Run once ← הודעת מעקב יצאה, `שלב מעקב` = 1.
- [ ] מסמנים `בוצע` ← Run once ← בקשת ביקורת יצאה עם הקישור הנכון.
- [ ] שני התרחישים ON, התראות שגיאה מגיעות למייל שלכם.
- [ ] בעל העסק התקין את אפליקציית Google Sheets ויודע לשנות סטטוס.
