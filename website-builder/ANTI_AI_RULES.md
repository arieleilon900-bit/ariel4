# כללים נגד "מראה של AI"

האתר צריך להיראות כאילו מעצבת גרפית ישבה עליו שעות, והטקסט צריך להישמע כאילו בעל העסק כתב אותו. המסמך מבוסס על מחקרים וניתוחים שמופיעים בסוף, ועל הניסיון מהאתרים במאגר. **חובה לעבור עליו לפני כל מסירה.**

## למה אתרים נראים AI
מודלים לא "מעצבים". הם חוזים את התבנית הכי נפוצה. התוצאה היא אותו אתר שוב ושוב:
- **המבנה הקבוע:** פתיח ממורכז ← שלושה כרטיסים ← ביקורות ← CTA.
- **העיצוב הקבוע:** אותם גופנים, אותו צל רך ואותו גרדיאנט.

## טקסט (הכי חשוב, הכי מסגיר)
| סימן AI | הנתון | מה עושים |
|---|---|---|
| **מקף ארוך (—)** | פי 10 יותר בטקסט AI (17 מול 2 ל-10K מילים) | **אסור.** נקודה, פסיק או משפט חדש. מקף קצר (–) רק בטווחים ("א׳–ה׳") |
| **שלישיות** ("מהיר, אמין ומקצועי") | פי 4 | שניים או ארבעה. או פריט אחד עם פרט מוחשי |
| **"לא רק X אלא Y" / "לא X. Y."** | פי 3 | לכתוב ישר את Y |
| **רשימות תבליטים ומודגשים** | פי 9–12 | פסקה רגילה. הדגשה רק למילה אחת במסך |
| **סימנים מיוחדים** (→ ✓ ★ ✦ ·) | פי 3; ✅ פי 167 | לא כקישוט. כוכבים רק בדירוג |
| **כותרות "סלוגן" של שתי שורות עם נקודה** ("אל תישארו בחוץ.") | נפוץ מאוד באתרי AI | כותרת שאומרת מה יש כאן: "מנעולן בחדרה" |
| **שאלה רטורית בכל סקציה** | | מקסימום אחת בכל האתר |
| **מילים ריקות**: מקצועי, איכותי, מוביל, חוויה, פתרון, שקט נפשי, בלי פשרות | | פרט אמיתי במקום: אזור, שעות, ציטוט של לקוח |
| **קול של מותג** ("אנחנו מאמינים...") בעסק של אדם אחד | | גוף ראשון של בעל העסק: "אני אריק. אם אפשר לתקן, אני מתקן" |

## עיצוב
| סימן AI | מה עושים במקום |
|---|---|
| **גופנים:** Inter, Rubik או Heebo לבד. זוגות קבועים (Space Grotesk / Instrument Serif) | גופן תצוגה עם אופי שמתאים לתחום (שילוט: Karantina; מלאכה: Frank Ruhl Libre) + גוף טקסט אחר (IBM Plex Sans Hebrew) |
| **צבעים:** גרדיאנט סגול-כחול, מצב כהה תמיד, "blob" רדיאלי ברקע | צבע בסיס אחד, דיו ואקסנט אחד שנלקח מהעולם של העסק (צהוב של מפתח גלם, ירוק של כרם) |
| **תווית קטנה עם קו מעל כל כותרת** ("—— השירותים שלנו") | בלי. הכותרת מספיקה |
| **כרטיסים זהים עם אייקון בריבוע מעוגל** | רשימה, טבלה, "שלט" עם קווי נקודות. כל סקציה בצורה אחרת |
| **מספור 01 / 02 / 03** | רק כשיש סדר אמיתי, ואז בצורה אחרת |
| **שורת נתונים עם קווי הפרדה** ("5.0 \| 24/7 \| 4 אזורים") | הנתון בתוך משפט, או במקום אחד שמצדיק אותו |
| **כפתורי גלולה (999px) בכל מקום, צל ענק, זכוכית (blur)** | פינות קטנות (4–6px), צל כמעט אפסי, רקע אטום |
| **טקסט נע (marquee), תגיות צפות, כל אלמנט "נחשף" בגלילה** | תנועה אחת עם סיבה. השאר סטטי |
| **כל סקציה באותו מבנה** (כותרת מימין + פסקה משמאל) | קצב משתנה: רחב, צר, טבלה, ציטוט גדול, פס |
| **אייקונים גנריים (Lucide) בכל כרטיס** | איור אחד מותאם (מפתח, תג מפתחות) או בלי אייקונים |

## מה נותן "יד של מעצבת"
- **קונספט אחד מהעולם של העסק** שחוזר לאורך כל האתר. אצל מנעולן: שלט של חנות מפתחות, תג מפתח, שלט שעות פתיחה על הדלת, מספר טלפון גדול כמו מדבקה על הרכב.
- **פרטים אמיתיים** שרק העסק הזה יכול להגיד: שם, אזור, שעות, ציטוטים, שומר שבת.
- **היררכיה ברורה:** אלמנט אחד ענק בכל מסך, השאר קטן.
- **טיפוגרפיה מדויקת:** גרש וגרשיים עבריים (׳ ״), מספרים בגופן מונו, מרווח שורות גדול בגוף הטקסט.
- **חוסר סימטריה מכוון,** ושוליים שונים בין הסקציות.
